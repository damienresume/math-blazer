How place value works

Every digit in a number has a value that depends on its place. Look at the number 4,382. Reading from the right, the places are:

  • The 2 is in the ones place, so it is worth 2.
  • The 8 is in the tens place, so it is worth 80.
  • The 3 is in the hundreds place, so it is worth 300.
  • The 4 is in the thousands place, so it is worth 4,000.

Add the values together and you get the number: 4,000 + 300 + 80 + 2 = 4,382.

Your turn

Answer each question on paper, then open the answer to check it.

Question 1

In the number 6,917, what is the value of the digit 9?

Show the answer

The value is 900. The 9 is in the hundreds place.

Question 2

Write this number with digits: 5 thousands, 0 hundreds, 7 tens and 2 ones.

Show the answer

The number is 5,072. The zero holds the hundreds place, so the 7 and the 2 stay in the tens and ones places.

Question 3

Which number is greater, 6,409 or 6,094?

Show the answer

6,409 is greater. Both numbers have 6 thousands. Then 6,409 has 4 hundreds and 6,094 has 0 hundreds.

Question 4

Round 3,846 to the nearest hundred.

Show the answer

The answer is 3,800. Look at the tens digit. It is 4, which is less than 5, so the hundreds digit stays the same and the lower digits become zero.
